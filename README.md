# Labs-Redes—Cisco-Packet-Tracer
Repositorio que contiene laboratorios y prácticas realizadas durante la asignatura de Redes 1 como parte de mi formación en Ingeniería en Sistemas.

Objetivo: Documentar y conservar prácticas relacionadas con la configuración, administración y troubleshooting de redes utilizando Cisco Packet Tracer.

Tecnologías y conceptos practicados
Direccionamiento IPv4
Subnetting
Configuración de routers y switches
Routing estático
Rutas por defecto
RIP y RIPv2
OSPF
DHCP
Pruebas de conectividad
Troubleshooting de redes
Laboratorios destacados
Routing estático y rutas por defecto

Configuración manual de rutas entre diferentes redes y utilización de rutas por defecto para permitir la comunicación entre múltiples segmentos.

RIP y RIPv2

Configuración de protocolos de routing dinámico utilizando RIP y RIPv2 para el intercambio automático de información de rutas entre routers.

OSPF

Implementación de OSPF en una topología de múltiples routers, configurando redes y verificando la conectividad y el aprendizaje de rutas.

DHCP

Configuración de servicios DHCP para la asignación automática de direcciones IP a dispositivos dentro de la red.

Herramienta utilizada
Cisco Packet Tracer
